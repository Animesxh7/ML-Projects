# Project 01 — RegressRight 🍷

**Machine Learning Model:** Linear Regression  
**Task:** Red Wine Quality Prediction  
**Type:** Supervised Learning — Regression

## Overview
RegressRight predicts wine quality scores using physicochemical features. The project covers data cleaning, exploratory data analysis, preprocessing, model training, evaluation, and an interactive Streamlit application.

## Tech Stack
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Streamlit
- Jupyter Notebook

## Project Files
The complete project includes:
- `app.py` — interactive Streamlit application
- `winequality-red.csv` — dataset
- `RegressRight_Linear_Regression.ipynb` — end-to-end ML notebook
- `requirements.txt` — dependencies
- `README.md` — project documentation

## Run Locally
```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## Dataset
UCI Machine Learning Repository — [Wine Quality Dataset](https://archive.ics.uci.edu/dataset/186/wine+quality)
